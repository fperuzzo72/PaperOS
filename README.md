# PaperOS

## A Philosophy of Calm Computing

PaperOS is first and foremost a philosophy of computing.

The operating system is the first implementation of that philosophy—not its purpose.

This repository therefore places the editorial work at the center of the project. The Founder's Edition defines the principles from which every architectural and engineering decision will emerge.

## Repository priorities

1. Founder's Edition
2. Manifesto
3. Architecture
4. Prototype
5. Implementation

The code explains *how*.

The book explains *why*.
