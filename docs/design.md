PaperOS Design Notes v0.1

See the Founder’s Edition (FoundersEdition/src/), particularly Chapters
3-6 and the Ownership chapter, for the reasoning behind these notes.
This document states the how. The book states the why.

Design principles

-   Keyboard-first interaction
-   Documents before applications
-   Context always visible
-   Predictable navigation
-   Minimal visual noise

Main workspace

The primary screen is the Desk.

It presents current work rather than applications.

Typical sections:

-   Recent documents
-   Journal
-   Tasks
-   Library
-   Archive
-   Terminal

Navigation

Arrow keys move.

Enter opens.

Backspace returns.

Esc opens the global menu.

Global menu

File

Edit

Search

Tools

System

Status bar

Always shows:

Current location

Current document

Current mode

Current keyboard hints

Touch

Touch is optional.

Every touch action must also be available from the keyboard.

Visual language

Every pixel should communicate information.

Animation is avoided unless it clearly improves understanding.
