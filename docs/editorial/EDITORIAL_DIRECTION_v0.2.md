# Editorial Direction — Revision v0.2

## Repository Vision

The editorial repository is the primary source of truth for the PaperOS philosophy.
The code explains *how* PaperOS works.
The Founder's Edition explains *why* it exists.

## Editorial Rules

- The book is the first official project of PaperOS.
- Every chapter is written as an individual Markdown document.
- The master manuscript is generated from the chapters.
- Every change is reviewed before entering the master manuscript.
- Documentation evolves before implementation whenever practical.
