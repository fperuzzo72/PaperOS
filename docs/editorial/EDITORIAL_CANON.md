# Editorial Canon

## Canonical Subtitle

PaperOS

*A Philosophy of Calm Computing*

Founder's Edition

## Canonical Closing Chapter

The Computer That Waits

## Canonical Editorial Position

PaperOS is a philosophy of computing whose first implementation is an
operating system.

The book is the foundation.

The implementation is the demonstration.

## Editorial Tone

The work is constructive rather than combative.

It recognizes the extraordinary achievements of modern computing while
arguing that another philosophy of computing deserves to exist.

## Guiding Principle

PaperOS is not an attempt to return to the past.

It is an attempt to carry its best ideas into the future.
