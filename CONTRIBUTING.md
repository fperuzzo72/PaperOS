Contributing to PaperOS

Before proposing a change, ask:

-   Does this make the system simpler?
-   Does it reduce distractions?
-   Does it preserve keyboard usability?
-   Does it respect open document formats?
-   Does it strengthen hardware independence?
-   Does it follow the manifesto?

If the answer is “no” to most of these questions, reconsider the
proposal.

The manifesto has priority over convenience.
